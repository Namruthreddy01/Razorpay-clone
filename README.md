🔹 Razorpay Payment UI (Frontend Only)

This project is a simple frontend interface for integrating Razorpay payment gateway using HTML, CSS, and JavaScript. It demonstrates how a payment button and checkout flow can be designed for a web application.

🚀 Features

* Clean and responsive payment UI
* Razorpay checkout button integration
* Simple and easy-to-understand structure
* Beginner-friendly project

🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* Razorpay Checkout (Frontend)

📌 Description

This project focuses only on the user interface and basic client-side integration of Razorpay. It does not include backend logic for order creation or payment verification.

⚙️ How to Use

1. Clone the repository
2. Open the index.html file in your browser
3. Add your Razorpay test key in the script
4. Click the payment button to test the UI

🔐 Note

This is a demo project. For real-world applications, backend integration is required to securely handle payments.
